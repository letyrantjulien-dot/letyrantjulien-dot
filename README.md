# InvisibleChaos

Open source web apps, e-paper firmware and growing systems, made in Berlin. Every app links one shared Impressum and privacy page: no account, no tracking, no ads, never Google Fonts.

Public here, newest first:

- **Tuner Bro**: an instrument tuner in the browser, sound analysed on the device, nothing recorded or sent.
- **The E!nkster family**: firmware for ESP32-S3 e-paper boards, with an offline knowledge shelf.
- **Radzeugnis**: Berlin's cycling map, with safety routing.
- **Quellcode**: Berlin's hand pumps on a map, with readers' photos and stories.

More apps live on the hub at [invisiblechaos.netlify.app](https://invisiblechaos.netlify.app). They come here one by one, each after a release check: no keys, no personal data, credits complete, MIT licence.

Built with AI assistance (Claude), stated openly. Every file is reviewed, credited and maintained by a person. These repositories are the maintained home, not a dump.
